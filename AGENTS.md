# Coding Agent Guidelines

## Project Overview
This is a Python practice and learning workspace. The purpose is to experiment with Python code, test concepts, and explore language features.

## Guidelines for AI Agents

### Code Style
- Use Python 3.x syntax
- Keep code clear and readable with meaningful variable names
- Add comments explaining non-obvious logic or learning concepts
- Follow PEP 8 conventions

### General Practices
- When adding new practice files or functions, include brief docstrings explaining the purpose
- Use type hints where appropriate to improve clarity
- Test any new functions or code snippets
- If practicing specific Python features, include explanatory comments

### Common Patterns
- Organize practice code by concept (e.g., `dict_practice.py`, `class_practice.py`)
- Keep files focused on a single topic or concept to aid learning
- Use clear print statements or simple test cases to verify behavior

---

*This workspace is optimized for learning and experimentation. Prioritize clarity and educational value over production-level optimization.*
